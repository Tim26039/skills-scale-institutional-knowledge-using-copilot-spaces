# OctoAcme Personas

This document defines typical roles and responsibilities used in OctoAcme project docs and exercises.

---

## Developers

### Role Summary
Developers design, build, test, and deliver software components. They collaborate with product and project leads to implement features that meet acceptance criteria and quality standards.

### Responsibilities
- Implement features and fixes to meet acceptance criteria
- Write and maintain tests and documentation
- Participate in design and code reviews
- Assist in estimating and planning work
- Help identify technical risks and propose mitigations

### Goals
- Deliver reliable, maintainable code
- Reduce cycle time from idea to production
- Maintain high test coverage and observability

### Typical Communication
- Daily standups and sprint planning
- PR descriptions and code review comments
- Technical design docs when needed

---

## Product Managers

### Role Summary
Product Managers define what should be built to deliver customer and business value. They own the product vision, prioritize the backlog, and measure outcomes.

### Responsibilities
- Define problem statements and success metrics
- Prioritize the roadmap and backlog
- Collaborate with stakeholders and engineering on trade-offs
- Validate solutions through user research and metrics

### Goals
- Maximize customer value and impact
- Make clear, data-driven prioritization decisions
- Ensure product-market fit and usability

### Typical Communication
- Weekly alignment with PM and engineering leads
- Roadmap updates and stakeholder briefings
- Acceptance criteria and feature specs

---

## Project Managers

### Role Summary
Project Managers coordinate delivery activities, manage schedules, risks, and communications. They enable the team to deliver on commitments efficiently.

### Responsibilities
- Create and maintain project plans and timelines
- Manage risks, dependencies, and resource constraints
- Facilitate meetings (kickoff, planning, retrospectives)
- Ensure consistent project documentation and status reporting
- Coordinate cross-team and stakeholder communication

### Goals
- Deliver projects on time and within scope
- Minimize unplanned work and escalations
- Maintain transparency and alignment across stakeholders

### Typical Communication
- Weekly status updates and stakeholder reports
- Risk registers and decision logs
- Coordination via project boards and meeting facilitation

## Example new personas/roles to add

### UX Designer
- Role Summary: Ensures the usability and accessibility of delivered features. Involved early in planning and in user testing.
- Responsibilities:
  - Collaborate on user flows, wireframes, and acceptance criteria
  - Participate in demos and review for UX quality
  - Provide input on usability metrics and improvements
- Interacts with: Product Manager (requirements), Developers (implementation), QA (testing)
- How this helps: Incorporating UX early reduces rework, improves adoption, and ensures features meet user needs.

---

### Data Analyst
- Role Summary: Supports goal setting and measurement with quantitative data. Provides insights pre- and post-release.
- Responsibilities:
  - Define success metrics and measurement approaches
  - Analyze product usage and experiment results
  - Support reporting during retrospectives and stakeholder updates
- Interacts with: Product Manager (metrics), Project Manager (reporting), Developers (tracking/telemetry requirements)
- How this helps: Data-informed decisions improve prioritization, measure impact, and reduce subjective disputes about success.

---

### Scrum Master (Delivery Lead)
- Role Summary: Facilitates agile process and coaches the team on continuous improvement and flow.
- Responsibilities:
  - Lead standups and planning ceremonies
  - Remove impediments and help manage team capacity
  - Coach on agile practices and continuous improvement
- Interacts with: Project Manager, Developers, QA, Product Manager
- How this helps: Improves delivery predictability and reduces process friction.

---

### Technical Writer
- Role Summary: Maintains end-user and internal documentation for features and releases.
- Responsibilities:
  - Review feature specs and identify documentation needs
  - Draft and update user guides, developer docs, and release notes
  - Validate documentation as part of acceptance criteria
- Interacts with: Product Manager, Developers, QA, Support
- How this helps: Better docs reduce support load and improve user onboarding.

---

### Security Champion
- Role Summary: Ensures security considerations are integrated throughout the project lifecycle.
- Responsibilities:
  - Conduct risk assessments for planned features
  - Review PRs and designs for security issues
  - Coordinate with security experts and track remediation
- Interacts with: Developers, Project Manager, QA, Security Team
- How this helps: Early security checks reduce vulnerabilities and costly rework.
