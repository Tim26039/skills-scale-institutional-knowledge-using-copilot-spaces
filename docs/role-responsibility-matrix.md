# Role Responsibility Matrix (RACI-style)

Purpose: provide a compact view of who is Responsible / Accountable / Consulted / Informed for common project activities.

| Activity | Primary (R/A) | Secondary (C) | Informed |
|---|---:|---|---|
| Project One-pager | Product Manager (A) | Project Manager (R) | Stakeholders |
| Backlog prioritization | Product Manager (A) | Developers, PM (C) | Stakeholders |
| Acceptance criteria | Product Manager (A) | Developers, QA (C) | PM |
| Sprint planning | Scrum Master (R) | Product Manager (C) | Team |
| Release approval | Project Manager / Product Manager (A) | QA, Security (C) | Support, Stakeholders |
| Security review | Security Champion (R) | Developers (C) | PM, Project Manager |
| Documentation | Technical Writer (R) | Developers (C) | Support |
| Measurement & analytics | Data Analyst (R) | Product Manager (C) | PM, Stakeholders |
