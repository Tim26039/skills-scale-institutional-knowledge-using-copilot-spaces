# OctoAcme Project Management Docs

This README provides an overview and links to all project management process documents for the OctoAcme team. Use this as a reference for our key processes, templates, and best practices.

## Summary of OctoAcme Project Management Processes

OctoAcme delivers projects using a lightweight, iterative process emphasizing:

- **Clear Ownership**: Defined roles including Project Manager, Product Manager, and team members
- **Structured Stages**: Well-defined entry (initiation), planning, execution, release, and continuous improvement stages
- **Artifacts & Documentation**: Comprehensive use of one-pagers, backlogs, checklists, risk registers, and retrospectives
- **Communication & Feedback**: Established feedback, communication, and escalation paths at each stage

This approach ensures transparency, accountability, and continuous refinement of our processes across all projects.
