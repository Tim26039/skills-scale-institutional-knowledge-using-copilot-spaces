# Process Improvements & Role Adoption Checklists

## Roles Addition Checklist
- [ ] Role summary drafted (purpose and scope)
- [ ] Responsibilities listed
- [ ] Interaction with existing roles described
- [ ] Example deliverables/artefacts provided
- [ ] Added to role-responsibility matrix
- [ ] Stakeholders / team agree to the role and owner

## Release checklist (template)
- [ ] All PRs merged
- [ ] CI passing and security scans complete
- [ ] Release notes drafted by Technical Writer
- [ ] Smoke tests defined and launch validated
- [ ] Monitoring and rollback plan in place

## Onboarding checklist for new roles
- [ ] Role introduced at team cadence (standup/demo)
- [ ] Role responsibilities added to project README
- [ ] Access and tooling provisioned (dashboards, tickets)
- [ ] First-cycle support assigned (mentor or buddy)
